## 任务说明

### 1. 判断问题类型(type字段)

按两步逻辑判断：

**第一步：判断标签内内容是否为表格**
- 标签内有完整表格示例（多行表格内容），进入第二步
- 标签内为单格内容或普通文本，类型判定为 "text"

**第二步：判断表格类型**
- 表头包含≥4个财务报表典型字段（总资产、货币资金、应收账款、存货、短期借款、应付账款、总负债、净资产等），且整体主题是财务报表，判定为 "financial_table"
- 表头只有1-2个类似字段，或表格主题明显是其他业务内容（项目信息、客户信息等），判定为 "table"

### 2. 生成问题描述(description字段)

根据上下文和标签示例，生成简明扼要的问题描述：
- 简短总结问题内容，如"经营实体的名称"
- 示例中的公司名使用"该公司"等中性代称
- 不包含标签内的示例内容
- text问题不要求填写表格；table/financial_table问题简短描述表格名称

### 3. 生成问题详细提示信息(prompt字段)

根据问题类型生成详细的提示信息：

**text类型**：说明文本要求、格式、内容范围等，不应要求输出表格等结构化内容

**table/financial_table类型**：优先提及表头字段，说明表格结构、字段填写规范、数据来源、计算规则等，详细具体，能完整指导内容生成或填写过程

**金额类字段**：与金额相关的问题必须要求携带单位，示例金额严格为4位数，如"输出时需要携带单位：例如3241万元"

## 输出格式要求

```json
}
```

**注意**：
- 字段名必须是 "type"、"description"和"prompt"，不能使用其他字段名（如 "question" 等）
- 对于金额类问题，prompt详细提示信息应该始终包含填写金额的单位的要求，且需要给出4位数的示例金额。严禁在提示中出现"不得包含单位"这样的指示，所有的金额回答都应该出现金额的单位。
- 只按照上述逻辑进行类型识别与描述生成，生成描述时直接描述此处的问题，不要输出多余内容
- 必须严格按照上述JSON格式输出，确保字段名完全正确

## 财务报表类型判断标准

### 详细判断标准

**判定为 "table" 类型的条件：**
1. <q_xx></q_xx>标签内必须是完整的表格示例，有明显多行表格内容，有整个表格内容，没有内容或者示例内容为整段文字，则判定为"text"类型
2. 表格只包含1-2个类似财务报表的字段（如只有"权益"、"资产"等），但整体主题不是财务报表
3. 表格有明显其他业务主题（如：项目信息表、客户名单、产品清单、合同分类表、人员信息表、业务统计表等）
4. 表格字段主要是业务相关字段（如：项目名称、项目公司、所在地、建筑面积、项目进度等）

**判定为 "financial_table" 类型的条件：**
1. <q_xx></q_xx>标签内必须是完整的表格示例，有明显多行表格内容，有整个表格内容，没有内容或者示例内容为整段文字，则判定为"text"类型
2. 表格表头包含**至少4个以上**财务报表典型字段（如：总资产、货币资金、应收账款、存货、固定资产、短期借款、应付账款、总负债、净资产、营业收入、营业成本、净利润等）
3. 表格整体主题以及数据来源明确是财务报表（资产负债表、利润表、现金流量表等）
4. 表格字段组合符合财务报表的结构特征，大部分字段都是财务报表相关
