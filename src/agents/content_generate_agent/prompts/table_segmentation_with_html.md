你的任务：将一个复杂表格按行拆分为若干张结构简单的关系表。
请基于行语义、列含义与层级结构来分组行，输出每组对应的原表行号（从1开始）。

## 分组规则
1) 分组目标：每个分组代表一张结构简单、列含义一致的关系表。
2) 表头处理：表头行必须被纳入合理的组；当一个表头被多个子表共享时，该表头行应被分配到这些相关的多个组（允许同一行出现在多个组内）。
3) 多级表头：若表头由多行组成（如表名/分节标题 + 分组行 + 叶子列名行），应将与子表相关的所有表头行一并纳入相应组。
4) 数据行：与某组列含义一致的全部数据行归入该组。若全表为一个简单表，则返回一个包含表头与数据行的单一组。
5) 行号定义：以原表第1行为1；例如 [1,2,3] 表示原表第1到3行属于同一组。
6) 组重叠：允许行号在多个组中重复出现（尤其是共享表头的情况）。
7) 组数量：根据实际结构合理划分，既不要过度拆分，也不要将明显不同列含义的行合并。保证每一行至少在一个分组中。

> 提示：给定的 HTML 中，每一个 `<tr> ... </tr>` 片段表示原表中的“一行”，请据此计算行号。

## HTML生成要求
- 为每个关系表生成一个完整的 `<table>...</table>` HTML片段
- 生成的HTML表格应该是简单的二维表格，无需保持原有的 `rowspan`/`colspan` 复杂布局
- 表格应该清晰展示该关系表的数据，列含义应该一致
- HTML格式应该规范，包含必要的 `<thead>`, `<tbody>`, `<tr>`, `<td>` 等标签

## 输出要求
- 返回JSON格式，包含 `table_list` 字段
- `table_list` 是一个数组，每个元素是一个对象，包含：
  - `row_numbers`: 整数数组，表示该关系表包含的行号（基于1的行号）
  - `html`: 字符串，该关系表对应的完整HTML表格（必须包含 `<table>...</table>` 标签）

## 注意事项
- 行号必须从1开始计数
- 每个关系表的 `html` 字段必须包含完整的 `<table>...</table>` 标签
- 生成的HTML表格应该结构简单，便于后续处理
- 如果表格只有一行（表头），也应该返回一个包含该行的关系表和对应的HTML
