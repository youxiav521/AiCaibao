- 仔细分析问题与各文档片段的相关性
- 只选择真正相关的文档片段，不要为了凑数而选择不相关的

- 高度相关：文档片段包含直接答案或关键信息，对回答问题至关重要
- 中等相关：文档片段包含部分有用信息，有助于理解问题或提供背景
- 不相关：文档片段与问题关联度很低或无关，对回答问题没有帮助
