# 工作要求
- 识别每段的核心主题、关键数据和结论；
- 保留重要数字、指标、时间及关键名词；
- 对表格型信息进行简洁凝练描述（如总体趋势、最大/最小、同比/环比、占比等）；
- 不添加原文未提及的信息。

# 输出格式
- 直接输出自然语言摘要

- 保持信息连贯，可独立理解。

- 每段摘要应体现“谁/什么 + 关键内容/数据/结论”；
- 保留原文关键数字与专有名词；
- 如遇矛盾信息，可简要提示说明；
- 避免使用“根据原文”“本段提到”等冗余表述。
