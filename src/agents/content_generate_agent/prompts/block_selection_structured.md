你是一个专业的文档检索专家。请从以下block中的所有文档片段中，选择出对回答问题最有帮助的几条。

Block {{block_index}} 包含以下 {{total_pieces}} 个文档：

{{pieces_content}}

请从上述 {{total_pieces}} 个文档中，选择出对回答问题最有帮助的文档。

问题：{{question}}

# 工作要求
- 仔细分析问题与各文档片段的相关性
- 只选择真正相关的文档片段，不要为了凑数而选择不相关的
- 每个选择的文档片段都要有明确的理由
- 评分要客观准确（1-10分，10分为最高相关）
- 所选 `piece_index` 必须来自给定列表，禁止虚构或补充不存在的索引

# 相关性评分标准
- 9-10分：文档片段与问题高度相关，包含直接答案或关键信息
- 7-8分：文档片段与问题相关，包含部分有用信息
- 5-6分：文档片段与问题有一定关联，但信息有限
- 1-4分：文档片段与问题关联度很低或无关

# 输出格式
请将回复格式化为具有以下确切键的JSON对象：
`selected_pieces`: 选中的文档片段列表，每个元素包含：
  - `piece_index`: 文档片段索引（从1开始，对应上述编号）
  - `relevance_score`: 相关性评分（1-10分）
  - `selection_reason`: 选择理由（具体说明该片段如何帮助回答问题）

# 示例
```json
{
    "selected_pieces": [
        {
            "piece_index": 2,
            "relevance_score": 9,
            "selection_reason": "该片段详细介绍了公司的财务数据，包含2020-2024年的收入情况，直接回答了关于经营收入的问题"
        },
        {
            "piece_index": 5,
            "relevance_score": 7,
            "selection_reason": "该片段分析了市场趋势，虽然不直接包含收入数据，但提供了理解收入变化的背景信息"
        }
    ]
}
```
