# 单文件风险信号识别代码流程说明

## 1. 入口与任务执行

- 接口入口：`POST /single-file/risk/jobs`
- 代码位置：`router.py`
- 执行模式：异步后台任务（`BackgroundTasks`）

处理流程：

1. 校验请求（`checkReportId`、`docContent`）
2. 生成 `jobId`，写入任务文件（`storage/policy_check/single_file_risk_signal_jobs/{jobId}.json`）
3. 后台执行 `_run_job_async`
4. 回调顺序：
   - `started`
   - `audited`
   - `completed`
   - 异常时回调 `error`

## 2. 服务主流程（规则召回 + LLM裁决）

- 核心代码：`service.py` 的 `SingleFileRiskSignalCheckService.analyze_request/analyze_resource_file`

主链路：

1. 输入标准化
   - 请求转 `ResourceFile`
   - 解析 `model_id / enable_llm / max_candidates / max_judge_concurrency / llm_retry_attempts`
2. 文档初步分类（复用 shared）
   - 调用 `shared/doc_profile.py` 的 `classify_doc_profile_with_llm_fallback`
   - 使用 `map_doc_types_to_policy_doc_types` 输出策略文档类型
   - 分类结果用于叠加“文档类型专属风险规则”（`DOC_TYPE_RISK_RULES`）
3. 文档预处理
   - 清洗文本（`MaterialCleaner`）
   - 构建证据块（`build_material_store`）
   - 组装并去重 segments
4. 规则候选召回
   - 通用规则：`RISK_RULES`
   - 类型规则：`DOC_TYPE_RISK_RULES`
   - 逐段按句切分，关键词命中生成 `RiskSignalCandidate`
   - 对 `VAGUE_EXPRESSION` 有可执行语境过滤（避免过度召回）
5. 候选裁决
   - `enable_llm=true`：LLM 结构化裁决（并发 + 重试）
   - 结构化解析失败：降级 raw 解析
   - LLM 全失败：`_fallback_judgment`（保守输出 `uncertain`）
   - `enable_llm=false`：直接走 `_fallback_judge_candidates`
6. 结果聚合
   - issue 去重合并
   - `overall_status` 规则：`fail > uncertain > pass`
   - 汇总 `statistics(high/medium/low)` + metadata

## 3. 输出口径

每条 issue 包含：

- `issueId`、`issueType`
- `severity`：`high / medium / low`
- `status`：`pass / fail / uncertain`
- `summary/reasoning/suggestion`
- `confidence`
- `evidence`（页码、elementId、segmentId、quote、role）
- `attributes`（命中关键词、规则作用域、文档类型等）

回调映射：

- `audited` 返回逐条风险结果（`results[]`）
- `completed` 返回汇总（`totalIssues/high/medium/low/passed/failed/uncertain/durationSeconds`）

## 4. 配置项与默认值

请求可调参数（`schemas.py`）：

- `modelId`：默认 `model_bailian_policy_check`
- `enableLlm`：默认 `true`
- `maxCandidates`：默认 `24`
- `maxJudgeConcurrency`：默认 `12`
- `llmRetryAttempts`：默认 `3`

## 5. 用时与统计建议

本地测试34页pdf输入完成时间在几秒内。

## 6. 本地测试脚本

- `single_file_risk_signal_local_test.py`

能力：

- 读取本地 JSON（单文件或目录批量）
- 直接改脚本顶部 `DEFAULT_*` 配置
- 支持覆盖 `model_id / enable_llm / max_candidates / max_judge_concurrency / llm_retry_attempts / 并发数`
- 打印 `started -> audited -> completed` 回调结构
- 落盘完整模型输出与回调 payload
