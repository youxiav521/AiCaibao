# 单文档合规检查接口

## 1. 概述

该接口用于对 `files[]` 中的文档执行合规审查，并通过回调返回结果给 Java 端。

- 回调路径：`POST /result/modelcallback`
- 回调事件：`started -> audited -> completed`（失败时为 `error`）
- 分类：固定为 `COMPLIANCE`
- 范围：固定为 `file`

## 2. 提交接口

- 方法：`POST /api/policy/single-file/check/jobs`
- Content-Type：`application/json`

## 3. 请求字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `checkReportId` | 是 | Java 任务主键 |
| `files` | 是 | 待审文件数组 |
| `files[].fileId` | 是 | 文件 ID |
| `files[].fileName` | 是 | 文件名 |
| `files[].docContent` | 是 | MinerU 解析结果（JSON 数组） |
| `frameworks` | 是 | 政策框架 |
| `modelId` | 否 | 模型 ID |
| `maxConcurrency` | 否 | 并发度 |
| `callBackURL` | 否 | 回调地址 |

## 4. 回调协议（Java 对接口径）

### 4.1 started

```json
{
  "event": "started",
  "checkReportId": "REPT-001",
  "fileId": "file_001",
  "category": "COMPLIANCE",
  "data": {
    "fileStatus": "P"
  }
}
```

### 4.2 audited

```json
{
  "event": "audited",
  "checkReportId": "REPT-001",
  "fileId": "file_001",
  "category": "COMPLIANCE",
  "data": {
    "fileId": "file_001",
    "docFileName": "demo.json",
    "fileStatus": "F",
    "results": [
      {
        "scope": "file",
        "category": "COMPLIANCE",
        "fileId": "file_001",
        "docFileName": "demo.json",
        "controlResult": {
          "status": "fail",
          "level": "HIGH",
          "title": "规则标题",
          "detail": "判定说明",
          "suggestion": "处理建议",
          "degraded": false
        },
        "rule": {
          "frameworkId": "FW-001",
          "requirementId": "REQ-001",
          "controlId": "CTRL-001"
        },
        "evidence": [
          {
            "sequenceId": 1,
            "fileId": "file_001",
            "elementIds": [10, 11],
            "pageNo": 2,
            "recommendation": "证据摘要",
            "quote": "证据引用"
          }
        ]
      }
    ]
  }
}
```

#### evidence 字段说明

`audited.data.results[].evidence[]` 对外字段为：

- `sequenceId`
- `fileId`
- `elementIds`
- `pageNo`（可选，新增）
- `recommendation`
- `quote`

### 4.3 completed

```json
{
  "event": "completed",
  "checkReportId": "REPT-001",
  "fileId": "file_001",
  "category": "COMPLIANCE",
  "data": {
    "totalRequirements": 10,
    "totalControls": 45,
    "passed": 38,
    "failed": 4,
    "uncertain": 3,
    "skipped": 0,
    "durationSeconds": 12.3,
    "passRate": "84.4%",
    "description": "File demo.json review completed."
  }
}
```

### 4.4 error

```json
{
  "event": "error",
  "checkReportId": "REPT-001",
  "fileId": "file_001",
  "category": "COMPLIANCE",
  "data": {
    "errorMessage": "RuntimeError: ..."
  }
}
```

## 5. 变更说明（2026-04-10）

- 对 Java 回调协议，当前仅新增 `evidence.pageNo`（可选）。
- 除此之外，`audited/completed/error/started` 对外字段保持不变。
- 内部审查流程新增的调试/判定字段仅内部使用，不纳入 Java 回调协议。
