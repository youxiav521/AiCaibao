# 一致性与风险识别回调数据结构示例

本文档用于对接 Java 回调解析，覆盖以下两个能力的全部回调事件结构：

- `single_file_consistency_checks`（单文档一致性检查）
- `single_file_risk_signal_checks`（单文件风险信号识别）

回调事件枚举（当前代码实际发送值）：

- `started`
- `audited`
- `completed`
- `error`

## 1. 单文档一致性检查（single_file_consistency_checks）

### 1.1 顶层结构

```json
{
  "checkReportId": "string",
  "fileId": "string",
  "event": "started|audited|completed|error",
  "category": "CONSISTENCY",
  "data": {}
}
```

### 1.2 started 示例

```json
{
  "checkReportId": "REPT-20260408-001",
  "fileId": "file_001",
  "event": "started",
  "category": "CONSISTENCY",
  "data": {
    "checkType": "single_doc_consistency",
    "fileStatus": "P"
  }
}
```

### 1.3 audited 示例

说明：

- `fileStatus`: 有问题为 `F`，无问题为 `S`
- `results`: 每条一致性问题一个元素；无问题时也会返回 1 条摘要结果（`issueType=NO_ISSUE`，含 `category`）
- `status`: 固定 `"running"`
- `checkType`: 固定 `"single_doc_consistency"`
- `result`: 完整模型结果（含 `overallStatus`、`issueCount`、`issues`、`statistics`、`metadata`）

### 1.4 completed 示例

说明：

- `issueCount == 0` 时，`consistent = 1`
- `status`: 固定 `"completed"`
- `checkType`: 固定 `"single_doc_consistency"`

```json
{
  "checkReportId": "REPT-20260408-001",
  "fileId": "file_001",
  "event": "completed",
  "category": "CONSISTENCY",
  "data": {
    "issueCount": 0,
    "inconsistent": 0,
    "possiblyInconsistent": 0,
    "insufficientInformation": 0,
    "consistent": 1,
    "durationSeconds": 8.42,
    "description": "未发现一致性冲突。",
    "status": "completed",
    "checkType": "single_doc_consistency",
    "result": {
      "documentId": "doc_xxx",
      "fileId": "file_001",
      "fileName": "sample_consistency.json",
      "overallStatus": "consistent",
      "summary": "未发现一致性冲突。",

      "statistics": {
        "inconsistent": 0,
        "possiblyInconsistent": 0,
        "insufficientInformation": 0
      },
      "metadata": {}
    }
  }
}
```

### 1.5 error 示例

```json
{
  "checkReportId": "REPT-20260408-001",
  "fileId": "file_001",
  "event": "error",

```

## 2. 单文件风险信号识别（single_file_risk_signal_checks）

### 2.1 顶层结构

```json
{
  "event": "started|audited|completed|error",
  "checkReportId": "string",
  "fileId": "string",
  "category": "RISK_SIGNAL",
  "data": {}
}
```

### 2.2 started 示例

```json
{
  "event": "started",
  "checkReportId": "REPT-20260408-002",
  "fileId": "file_002",
  "category": "RISK_SIGNAL",
  "data": {
    "fileStatus": "P"
  }
}
```

### 2.3 audited 示例

说明：

- `fileStatus`: 有问题为 `F`，无问题为 `S`
- `results`: 每条风险问题一个元素；无问题时也会返回 1 条摘要结果（`issueType=NO_ISSUE`，含 `category`）

```json
{
  "event": "audited",
  "checkReportId": "REPT-20260408-002",
  "fileId": "file_002",
  "category": "RISK_SIGNAL",
  "data": {
    "fileId": "file_002",
    "docFileName": "sample_risk.json",
    "fileStatus": "F",
    "results": [
      {
        "scope": "file",
        "category": "RISK_SIGNAL",
        "fileId": "file_002",
        "docFileName": "sample_risk.json",
        "issueType": "LIABILITY_DISCLAIMER",
        "controlResult": {
          "status": "fail",
          "level": "HIGH",
          "title": "存在免责条款风险",
          "detail": "条款包含“本方不承担任何责任”等绝对免责表达。",
          "suggestion": "补充责任边界与适用条件。",
          "degraded": false
        },
        "attributes": {
          "matchedKeywords": ["免责", "不承担任何责任"],
          "ruleScope": "general",
          "ruleDocType": "CONTRACT_AND_PAYMENT"
        },
        "evidence": [
          {
            "sequenceId": 1,
            "fileId": "file_002",
            "elementIds": [88],
            "pageNo": 6,
            "quote": "本方在任何情况下均不承担任何责任。",
            "recommendation": "条款包含绝对免责表达，请人工复核。",
            "role": "mention"
          }
        ]
      }
    ]
  }
}
```

### 2.4 completed 示例

说明：

- `totalIssues == 0` 时，`passed = 1`

```json
{
  "event": "completed",
  "checkReportId": "REPT-20260408-002",
  "fileId": "file_002",
  "category": "RISK_SIGNAL",
  "data": {
    "totalIssues": 0,
    "high": 0,
    "medium": 0,
    "low": 0,
    "passed": 1,
    "failed": 0,
    "uncertain": 0,
    "durationSeconds": 5.67,
    "description": "未发现明显高风险表述。"
  }
}
```

### 2.5 error 示例

```json
{
  "event": "error",
  "checkReportId": "REPT-20260408-002",
  "fileId": "file_002",
  "category": "RISK_SIGNAL",
  "data": {
    "errorMessage": "ValidationError: ...\\nTraceback ..."
  }
}
```

## 3. Java 侧重点核对

请重点确认以下点：

- 事件枚举是否包含并处理：`started/audited/completed/error`
- 顶层字段名是否按 camelCase 解析：`checkReportId`、`fileId`、`category`、`data`
- 一致性 `audited.data` 内是否识别：`checkType`、`status`、`result`
- 风险识别 `completed.data` 内是否识别：`totalIssues`、`passed`、`failed`、`uncertain`
