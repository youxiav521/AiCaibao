参考Claude Code生成git message的最佳实践

**message内容:**
是要描述所有这些提交背后核心的一个或多个要达到的目的, 你可以按照以下思路去生成:
1. 寻找变更: 找到所有修改点, 确认哪些修改是重要的, 哪些是次要的
2. 猜测目的: 对重要的修改点进行总结和猜测他们要达成的目的. 
3. 分清主次: 去掉相比之下显得很不重要的修改
4. 输出目的: 对目的进行合并和排序, 确认用户这次commit最重要要达到的业务需求 / 非功能需求目的

**message格式**
1. 仅列举要达成的目的, **不要**罗列改了哪些代码
2. 简洁, 重点突出
3. 多个目的, 可以使用list
4. 最后添加 `Co-authored-by: [Trae]`
